# VitalHomeX

A responsive healthcare-oriented web interface built with HTML and CSS. The repository contains landing-page, login, and registration experiences together with the visual assets used by the site.

## Included

- Healthcare landing page
- Login and sign-up interfaces
- Responsive layout and custom styling
- Locally managed image assets

## Technology

HTML5 · CSS3

## Run locally

Clone the repository and open `heallyf.html` in a browser. A lightweight static server can also be used:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000/heallyf.html`.

## Status

This is a front-end learning project. Authentication screens are interface prototypes unless connected to a backend service.
